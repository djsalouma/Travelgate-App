✨ Powerful Features

Everything you need for modern attendance management

Location-Based Tracking

Automatically tracks attendance when employees are within 1km radius of your company building. Uses GPS for accurate location detection.

Clock In/Out System

Simple and intuitive clock-in and clock-out functionality with location verification. Supports grace periods for flexibility.

Comprehensive Reports

Generate detailed attendance reports (daily, weekly, monthly, yearly). Export to Excel for easy analysis and record-keeping.

Employee Management

Full employee management system. Add, edit, activate, or deactivate employees. Organize by departments and positions.

Cross-Platform Support

Works seamlessly on iOS, Android, and Windows Desktop. Same great experience on all devices and operating systems.

Smart Notifications

Automatic reminders for clock-in/out. Alerts for late arrivals, early departures, and when outside the designated area.

Offline Support

Full functionality without internet connection. Data syncs automatically when connection is restored.

Secure & Private

All data stored locally on device. Location tracking only when app is in use. Compliant with privacy regulations.

⚡ How It Works

Simple and intuitive process for everyone

1

Download & Install

Install the app on your device from the app store or download the desktop version for Windows.

2

Login to Your Account

Sign in with your company credentials. Different roles (Admin, Employee) have different access levels.

3

Enable Location

Grant location permissions so the app can detect when you're at work. This is required for clock-in/out.

4

Clock In/Out

When you arrive at work, clock in. When you leave, clock out. The app verifies you're within the company radius.

5

View Reports

Admins can view attendance reports, generate Excel files, and monitor all employees in real-time.

🚀 Quick Setup Guide

Get started in just a few minutes

Step-by-Step Installation

1️⃣ Install Flutter SDK

Make sure you have Flutter installed on your system.

flutter --version

2️⃣ Clone the Repository

Download the project files.

git clone https://github.com/djsalouma/Travelgate-App.git
cd Travelgate-App

3️⃣ Install Dependencies

Install all required packages.

flutter pub get

4️⃣ Generate Type Adapters

Generate Hive database type adapters.

flutter pub run build_runner build

5️⃣ Run the App

Start the app on your preferred platform.

# Android
flutter run -d android

# iOS
flutter run -d ios

# Windows
flutter run -d windows
